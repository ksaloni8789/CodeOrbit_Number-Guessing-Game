# 🎯 Number Guessing Game

## 📌 About the Project

Number Guessing Game is a simple Python-based game in which the computer generates a random number between 1 and 25. The player has 5 attempts to guess the correct number. The game provides hints to help the player guess higher or lower and allows replaying the game.

After each guess, the program provides a hint:

- **Too Low:** Try a higher number.
- **Too High:** Try a lower number.
- **Correct Guess:** Congratulations! You win the game.

After each round, the player can choose to play again or exit the game.

## ✨ Features

- Random number generation
- Number range from 1 to 25
- Maximum of 5 attempts per round
- Hints for incorrect guesses
- Input validation for invalid entries
- Option to play multiple rounds
- Beginner-friendly Python code

## 🛠️ Technologies Used

- **Programming Language:** Python

## 🚀 How to Run the Project

**Step 1:** Clone the repository or download the project files.

**Step 2:** Open the project folder in your code editor.

**Step 3:** Open a terminal in the project folder.

**Step 4:** Run the following command:

```bash
python main.py
```

If your system uses `python3`, run:

```bash
python3 main.py
```

## 🎮 How to Play

1. Start the program.
2. Enter a number between 1 and 25.
3. Read the hint displayed by the program.
4. Try to guess the correct number within 5 attempts.
5. Enter `yes` or `y` to play another round.
6. Enter `no` to exit the game.
